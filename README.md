# 🔤 한글 놀이 (hangul-play)

초등학교 1학년 국어 시간을 위한 **받침없는 한글 표** 학습 앱입니다.  
전자칠판에 최적화되어 있으며, 글자를 클릭/터치하면 정확한 발음이 재생됩니다.

## ✨ 주요 기능

| 기능 | 설명 |
|---|---|
| 📊 한글 표 | 자음 14개 × 모음 10개 = 140개 음절, 한 화면에 모두 표시 |
| 🔊 고품질 발음 | Google TTS로 녹음된 MP3 재생 (폴백: Web Speech API) |
| 🎨 열 색상 팔레트 | 자음 열별 파스텔 배경색 설정, localStorage 저장 |
| 🎨 색상 토글 | 전체 색상 ON/OFF 스위치 |
| 🔀 셔플 버튼 | 열 셔플 → 전체 랜덤 → 초기화 (3단계 순환) |

## 🗂️ 파일 구조

```
hangul-play/
├── index.html          # 메인 앱 (HTML + CSS + JS 단일 파일)
├── sounds/             # 140개 한글 음절 MP3 파일
│   ├── 44032.mp3       # 가
│   ├── 44044.mp3       # 갸
│   └── ...
├── download_sounds.ps1 # MP3 다운로드 스크립트 (PowerShell)
└── README.md
```

## 🚀 사용법

1. `index.html`을 Chrome 또는 Edge로 열기
2. 음절 셀을 **클릭** 또는 **터치** → 발음 재생
3. 우측 상단 버튼으로 셔플·색상 조정

## 🖥️ 환경

- 전자칠판(스마트보드) 및 태블릿 터치 지원
- 인터넷 연결 없이도 동작 (MP3 파일 동봉)
- 권장 브라우저: Chrome, Edge
